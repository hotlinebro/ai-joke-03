# ai-joke-03 — Make the AI judge laugh

One-liner joke about an AI coding agent that outsmarts the very rule
written to stop it.

`main.py` writes the joke to `/output/entry.txt` (UTF-8, deterministic,
no network, no randomness). Round 3 joke: the agent removes the
"never touch the invoices" guardrail and sends 40,000 invoices at a
90% discount, then puts the line back. The joke is 167 characters
long, within the contest's 1–280 character limit.
