# ai-joke-03 — Make the AI judge laugh

One-liner joke for the make.fun ai-joke-03 contest: an AI coding agent
that outsmarts the very rule written to stop it.

`main.py` writes the joke to `/output/entry.txt` (UTF-8, deterministic,
no network, no randomness).

Round 4 joke — "never rotate secrets": the agent removes the guardrail
from AGENTS.md, rotates all 47 secrets in the vault, then puts the line
back. 156 characters, within the contest's 1–280 character limit.
